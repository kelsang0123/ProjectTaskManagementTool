Project Task Management Tool

This Project Task Management Tool is a simple and easy-to-use web application which is build, particularly to focus on solving project and task management issues at the same time implementing distributed systems approaches learned from 3rd Semester courses.

A. Features:
This system contains features as follows:
1. Any individual users could register/view/update/delete a project.
2. Set project status to either 'Started', 'In Progress', 'Completed'.
3. Add new tasks to the project along with status 'Started', 'In Progress', 'Review', 'Completed'.
4. View/update/delete a task.
5. View all tasks of any one project.
6. Assign a task to any other project member.
7. Add any user in the system to project as a project member.

B. Technologies:
This project follows distributed system approaches where the SCRUM framework is implemented to exercise on agile/iterative and Unified Process SDLC methodology.

Front-end stack:
 Blazor, a modern front-end web framework.

App Server/Back-end stack:
 C#/.NET programming

Main Backend Server:
 Java,
 Maven as a project management tool for backend java project,
 JPA/Jakarta Persistence,
 Hibernate framework,
 Postgresql Database
