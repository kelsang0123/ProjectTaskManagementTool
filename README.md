Project Task Management Tool

The Project Task Management Tool is build, particularly to focus on solving project and task management issues in the same time implementing distributed systems approach learned from 3rd Semester courses.

A. Features:
This system contains features as follows:
1. Any individual users could register/view/update/delete a project.
2. Set project status to either 'Started', 'In Progress', 'Completed'.
3. Add new tasks to the project along with status 'Started', 'In Progress', 'Review', 'Completed'.
4. View/update/delete a task.
5. View all tasks of any one project.
6. Assign a task to any other project member.
7. Add any user in the system to project as a project member.

B. Technology:
This project follows distributed system approaches where the developer implemented SCRUM framework for agile/iterative and Unified Process SDLC methodology.

Front-end stack:
a. Blazor

App Server/Back-end stack:
a. C#/.NET programming

Main Backend Server:
a. Java
b. Maven as a project management tool for backend java project.
c. JPA/Jakarta Persistence
d. Hibernate framework
e. Postgresql Database
