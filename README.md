Project Task Management Tool

Project Task Management Tool in this GitHub repo is a simple and easy-to-use web application which is designed and build, particularly to focus on solving project and task management issues at the same time implementing distributed systems approaches as part of 3rd Semester program.

A. Features:
This system contains features as follows:
1. register/view/update/delete a project.
2. set their project status to either 'Started', 'In Progress', 'Completed'.
3. Add new tasks to the project along with status 'Started', 'In Progress', 'Review', 'Completed'.
4. View/update/delete a task.
5. View all tasks of any one project.
6. Assign a task to any other project member.
7. Add any user in the system to project as a project member.

B. Technologies:
This project follows distributed system approaches where the SCRUM framework is implemented to exercise on distributed system concepts and technologies, agile/iterative and Unified Process SDLC methodology.

In the distributed system, there are several architectural designs that can be implemented to build a working software applications. This project follows three-tier architectural design (i.e. Front-end/UI, App server/Backend and Main Server/Backend). The technologies that are implemented on each stack to carry out this architectural design in this project are mentioned below: 

Front-end stack:
 Blazor, a modern front-end web framework.

App Server/Back-end stack:
 C#/.NET programming

Main Backend Server:
 Java,
 Maven as a project management tool for backend java project,
 JPA/Jakarta Persistence,
 Hibernate framework,
 Postgresql Database
