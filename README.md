Project Task Management Tool

Project Task Management Tool in this GitHub repo is a simple and easy-to-use web application which is designed and build, particularly to focus on solving project and task management issues at the same time implementing distributed systems approaches as part of 3rd Semester program.

A. Features:
This system contains features as follows:
1. register or delete a project.
2. view list of all created projects and projects that user is part of or responsible for accomplishing that project.
3. Sign up user with user credentials such as first name, last name, email and password.
4. Login and logout the user with credentials like email and password.
5. set or change their project status to either 'Started', 'In Progress', 'Completed'.
6. set or change project title and description.
7. Click one project from the project list to view selected project details briefly.
8. Add new task to the project with task title and status 'Started', 'In Progress', 'Review', 'Completed'.
9. Delete a task.
10. Change task title.
11. set or change task status to either 'Started', 'In Progress', 'Review', 'Completed'.
12. View all tasks of any one project.
13. Add or Remove a user to or from a project as a project member.
14. Assign or Unassign a task to or from the specific project member of the project.

B. Technologies:
This project follows distributed system approaches where the SCRUM framework is implemented to exercise on distributed system concepts and technologies, agile/iterative and Unified Process SDLC methodology.

In the distributed system, there are several architectural designs that can be implemented to build a working software applications. This project follows three-tier architectural design (i.e. Front-end/UI, App server/Backend and Main Server/Backend). The technologies that are implemented on each stack to carry out this architectural design in this project are as follows: 

Front-end stack:
 Blazor, a modern front-end web framework.

App Server/Back-end stack:
 C#/.NET programming

Main Backend Server:
 Java,
 Maven as a project management tool for backend java project,
 JPA/Jakarta Persistence,
 Hibernate framework,
 PostgreSQL Database
